## Memory Acquisition

O propósito deste repositório é documentar meu estudo prático e teórico a respeito da aquisição de memória no contexto da análise forense digital, expondo alguns conceitos fundamentais sobre o que é a aquisição de memória, sua finalidade na investigação forense, a importância dos dados voláteis e princípios relacionados à preservação e integridade das evidências obtidas durante o processo, além de registrar experimentos práticos sobre procedimentos, técnicas e ferramentas utilizadas para realização da aquisição de memória em diferentes ambientes computacionais modernos.
